# The Tasty House 🍽️

A responsive restaurant and café website created as part of Future Interns Task 3.

## About the Project

The Tasty House is a modern restaurant and café website designed to provide visitors with information about the restaurant, menu, contact details, and ordering interaction.

## Features

* Responsive restaurant website
* Home section
* About section
* Why Choose Us section
* Menu cards with prices
* Order Now button interaction
* Contact section
* Get in Touch interaction
* Responsive mobile design
* Smooth navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript
